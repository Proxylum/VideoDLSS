# Конвенции пассов (raw ↔ DLSS)

> Заполняется в этапе 1 вместе с `core/convert/` и юнит-тестами (ТЗ §5). Формулы фиксируются
> здесь один раз и переиспользуются всеми стадиями.

## Что будет описано
- `depth_raw` (float32, метры или relative с флагом) → `depth_dlss` (reverse-Z в [0,1], 1 = near)
  с near/far из манифеста; обратное преобразование.
- `mv_raw` (forward flow t→t+1, пиксели исходного разрешения) → `mv_dlss` (backward t→t−1, знак и
  ориентация Y по DLSS Programming Guide, масштаб под целевое разрешение, дилатация 1–2 px по границам глубины).
- Формат `manifest.json` и правила импорта без манифеста.

## Уже зафиксировано (этап 0)
- Кадры цвета в этапе 0 — 8-бит YUV 4:2:0, tightly packed (`Y`, затем `U`, затем `V`; ширина хромы
  `ceil(w/2)`, высота `ceil(h/2)`). Это внутренний формат `CpuFrame`, не формат экспорта.
- Нумерация кадров — 0-based в порядке декодирования; `pts` — в time base исходного потока.
