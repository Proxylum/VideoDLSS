## Что делаем

1. **`core/gpu/Ngx`** — общий рантайм NGX (вынос из `DlssUpscaler`): `Runtime::Acquire(device, searchPaths)` с
   рефкаунтом, лог-коллбек, `ResultName`/`Check`, `AppDataPath`. DLSS SR переводится на него без изменения поведения.
2. **`core/stages/tonemap/Tonemapper`** (`Tonemap.hlsl`): compute RGBA16F → RGBA16F; вход `srgb | linear | pq | hlg`,
   экспозиция, кривая `passthrough | aces | reinhard` (ACES — fitted Narkowicz), выход — display-referred sRGB [0, 1]
   (то, что принимает NR: ComfyUI подаёт clamp [0,1]). Для SDR-источников v1 по умолчанию `passthrough`; PQ/HLG
   готовы к 10-битному декодированию (сейчас декодер даёт 8-бит 4:2:0 — HACK этапа 0).
3. **`core/stages/nr/`**
   - `INrBackend` — `Init(device, NrConfig)`, `Evaluate(cl, NrInputs{color, depth, mv, reset}, output)`, `Describe`;
     фабрика `ngx | stub`; `NrAvailable()` (DLL, форвардер, сборка без SDK — инструкция без устройства);
     `NvidiaDriverFromUmd`, `GpuArchitectureFromName`, `NrDiagnostics` (GPU, архитектура, драйвер, DLL + SHA-256,
     результаты `Init_Ext` и `CreateFeature(18)`, подсказка).
   - `NgxNrBackend` — Feature 18: проверка драйвера ≥ 616.56 (`--skip-driver-check` для экспериментов), NVIDIA-GPU,
     лог GPU/архитектуры/DLL/SHA-256/форвардера, ядро через `ngx::Runtime`, `LoadLibraryEx(nvngx_dlssnr.dll)`,
     форвардер **`nvngx.dll_dlssvid.dll`** (наш, `core/stages/nr/forwarder/`, отдельная DLL-цель; экспорты
     `dlssvid_nr_call_{init,create,evaluate,release}` принимают указатель на функцию сниппета — калька `caller_shim`
     ComfyUI), `Init_Ext` сниппета с перебором ABI (порядок «info, version» ComfyUI → публичный «version, info» →
     вариант OptiScaler с блоком параметров), блок параметров `capability` (OptiScaler) или `alloc` (ComfyUI) с
     автоповтором при неудаче создания, все `DLSSNR.*` при создании и заново при каждом evaluate (блок общий),
     `CreateFeature(18)` в `Init` (scratch-текстуры) — результат в лог; `FAIL_FeatureNotSupported` на не-Blackwell →
     подсказка `dlssvid nr-patch`; `FAIL_PlatformError` → диагностика форвардера. Guides: `depth_dlss` (R32F, reverse-Z,
     `DepthInverted=1`) и `mv_dlss` (пиксели, backward — `MVecScale=1`) субректами в своём разрешении; без MV — «still»
     (`Reset=1` на каждом кадре), с MV — temporal (`Reset` на первом кадре).
   - `StubNrBackend` (`StubNr.hlsl`) — детерминированная «правка» (локальный контраст + тон по `intensity`) для WARP:
     проверяет стадию, resolve, маски, temporal, pass count, model resolution без DLL. В продукте — только явно
     `--backend stub`, без автоматического fallback (результат заглушки не выдаём за NR).
   - `NrCompose` (`NrCompose.hlsl`) — resolve: при model scale = 1 правка берётся напрямую, иначе **перенос отношением**
     (HACK, упрощённый resolve OptiScaler: `edited = original · clamp(model↑ / proxy↑, 1/maxRatio, maxRatio)` с силой
     `transfer`); маски: `ui`/`ignore` → защита (возврат к входу), `face`/`skin` → множитель силы правки `--skin-blend`;
     **temporal-фильтр** (опция, HACK против мерцания пропатченных DLL): смешивание с предыдущим выходом, смещённым по
     `mv_dlss`, с порогом по разности цвета.
   - `NrStage` — вход: `color_sr` (папка `--color-dir`, по умолчанию `<passes>/color_sr`, если есть; или слот кэша) либо
     декодированный кадр; тонмаппинг → [downsample до model scale] → N проходов модели (свои фичи/история) → resolve с
     масками и temporal → `color_nr` (EXR half / PNG16) + слот кэша + превью `--video`; guides из `--depth-dir`/`--mv-dir`
     (по умолчанию `<passes>/depth_dlss`, `<passes>/mv_dlss`) или слота; `--no-guides` для A/B; маски из
     `<passes>/mask_{ui,ignore,face,skin}/` (пассы kind `mask`, PNG 8-бит). Недоступный бэкенд: в CLI — ошибка с
     инструкцией (код 1), в пайплайне (`disableWhenUnavailable`) — стадия отключается с сообщением, кадры идут дальше.
   - `NrPatch` — обёртка dlssnr-patcher: поиск python (`--python`, `DLSSVID_PYTHON`, `python`), патчера, CUDA 13.3
     (`--cuda-bin`, `CUDA_PATH_V13_3`), SHA-256 входа и результата, вывод в `bin/nvidia/nvngx_dlssnr.dll`.
4. **CLI**: `dlssvid nr -i in.mp4 -o passes [--color-dir] [--depth-dir] [--mv-dir] [--masks-dir] [--backend ngx|stub]
   [--intensity] [--style natural|cinematic|default|N] [--preset 0..3] [--local-tone] [--local-structure]
   [--skin-structure] [--auto-mask] [--passes 1|2] [--model-scale] [--transfer] [--max-ratio] [--no-guides]
   [--temporal a] [--temporal-threshold] [--skin-blend] [--tonemap passthrough|aces|reinhard] [--exposure]
   [--input-transfer srgb|linear|pq|hlg] [--format] [--video --codec] [--frames] [--warp] [--dll-dir]
   [--params-block capability|alloc] [--skip-driver-check] [--check] [--json]`; `dlssvid nr-patch --input <dll>
   [--output] [--patcher] [--cuda-bin] [--arch ada|ampere|turing|blackwell|all] [--python] [--dry-run]`.
5. **GUI**: стадия `nr` в `Project::DefaultStages()` (после `upscale`; `color_sr` подхватывается автоматически); в панели
   проекта у стадии `nr` кнопка **«Пропатчить DLL…»** (выбор исходной `nvngx_dlssnr.dll` → задача `nr-patch` в очереди,
   лог в панели); `color_nr` во вьюпорте — A/B через 2x2 и wipe.
6. **Тесты**: юнит — `NvidiaDriverFromUmd` (591.86, 616.56, порог), архитектура по имени, инструкции `NrAvailable`,
   сборка командной строки патчера, форвардер (загружается, имя содержит `nvngx.dll`, вызовы проходят и возвращают код),
   Tonemapper на WARP (passthrough — тождество, ACES на известных значениях, sRGB↔linear, PQ/HLG), NrCompose на WARP
   (direct — тождество, перенос отношением, маски, temporal); интеграционные — `NrStage` со `stub` на WARP (`color_nr`,
   манифест, слот, вход из `color_sr`, guides/no-guides, 2 прохода, model scale 0.5, маски, temporal, превью), `ngx`
   без DLL → инструкция / отключение без падения, реальный NR на NVIDIA GPU с DLL (SKIP иначе), CLI `nr`/`nr --check`/
   `nr-patch` (фейковый патчер на python) как процессы.
7. **Документация**: `docs/architecture.md` (стадия 6, HACK-строки: форвардер, перенос отношением, temporal, заглушка),

   с guides / без, temporal, мс/кадр отдельно для Ada и Blackwell — результаты после TASK-0011), README, `app/README.md`.

## Открытые вопросы
- ABI `Init_Ext` сниппета: два эталона расходятся (ComfyUI: `(…, info, version)`; OptiScaler: `(…, version, params)`) —
  перебираем варианты и логируем, какой сработал; закрепить после первого запуска с DLL.
- Формат MV: ComfyUI — `R16G16_FLOAT` (UV), OptiScaler — текстура игры (пиксели); мы подаём `mv_dlss` как есть
  (`R32G32_FLOAT`, пиксели, `MVecScale=1`); при `FAIL_UnsupportedInputFormat` — конвертация в RG16F.
- Блок параметров (`capability` vs `alloc`) — по умолчанию OptiScaler, автоповтор другим при неудаче создания.
- Маски: у модели нет входа масок (кроме UI-слоя Streamline и автомаски кожи) — применяем на этапе resolve.
- Мерцание пропатченных DLL: guides обязательны; temporal-фильтр — опция; измерить после TASK-0011.

## Отложено / вне этапа
- 10-битный/HDR декодер (PQ/HLG на входе тонмаппинга ждут его), UI-слой Streamline (`DLSSNR.UI/UIAlpha`), детекция
  смены сцены для `Reset`, копия результата в слот без CPU, D3D11/Vulkan пути.

## Приёмка (ТЗ §8–9)
- `dlssvid nr --backend stub` даёт `color_nr` на любом GPU (WARP); `--backend ngx` без DLL/драйвера печатает инструкцию и
  завершается кодом 1, в пайплайне стадия отключается; с DLL — лог архитектуры, SHA-256, `CreateFeature(18)`;
  `nr-patch` запускает патчер и кладёт результат в `bin/nvidia/`; A/B с guides и без, temporal как опция;
  HACK-строки в `docs/architecture.md`; PR.
